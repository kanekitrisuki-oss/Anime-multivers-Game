# Anime Multiverse

Version GitHub du site Anime Multiverse.

## GitHub Pages
Le fichier `index.html` est prêt à être publié avec GitHub Pages.

**Important :** GitHub Pages héberge uniquement les fichiers statiques. Le mode multijoueur (combats et Qui est-ce ?) utilise `server.js` et doit être lancé sur un hébergeur Node.js/WebSocket séparé.

## Multijoueur
Le serveur fourni reste inchangé. Lance-le avec :

```bash
npm install
npm start
```

Puis configure l'adresse du serveur multijoueur dans le site si nécessaire.
