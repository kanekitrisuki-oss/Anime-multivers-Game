ANIME MULTIVERSE — MULTIJOUEUR

1. Installe Node.js (version récente).
2. Dans ce dossier, ouvre un terminal.
3. Lance : npm install
4. Puis : npm start
5. Ouvre http://localhost:3000 dans ton navigateur.

COMBAT EN LIGNE
- Crée une salle Combat.
- Partage le code avec 1 à 3 autres joueurs.
- Sélectionne les univers dans l'onglet Histoire avant de lancer.
- Chaque joueur reçoit 4 compétences aléatoires inspirées des univers sélectionnés.
- Chaque joueur reçoit un passif secret visible uniquement par lui.
- Le serveur gère les tours, PV et dégâts.

QUI EST-CE ? EN LIGNE
- Crée une salle Qui est-ce ? et partage le code.
- Chaque joueur reçoit un personnage secret différent.
- Ton personnage est visible uniquement par toi.
- À ton tour, pose une question à l'autre joueur.
- L'autre répond Oui / Non / Je ne sais pas.
- Puis tente de deviner son personnage.

Pour jouer sur Internet avec des amis hors de ton réseau local, héberge ce serveur Node.js sur une machine/serveur accessible par Internet et ouvre le port choisi. Le client utilise automatiquement HTTPS/WSS si le site est servi en HTTPS.
